## 👨‍💻 Sobre mim

- 🌱 **Aprofundando conhecimentos em:** Arquiteturas baseadas em Agentes de IA (GenAI), Microsserviços em Python (**FastAPI**), Cloud (**AWS**) e DevOps & Observabilidade (**Docker, Grafana, Prometheus, Loki**).
- 🛠️ **Experiência prática com:** Desenvolvimento Full Stack (**Python, FastAPI, Java, TypeScript, Angular, Next.js, React Native**), Bancos de Dados (**PostgreSQL, MongoDB**), sistemas embarcados (**ESP32, C/C++**) e prototipagem no Laboratório Maker.
- 🎯 **Objetivo:** Busco desafios e oportunidades em **Inteligência Artificial / GenAI, Engenharia de Software e Backend** onde eu possa transformar problemas complexos em produtos inteligentes e de alto impacto.
